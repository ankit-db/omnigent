# Harness logo attribution

Native logo paths for Codex, Claude Code, Cursor, Kiro, OpenCode, Kimi,
Antigravity, and Goose are converted from the existing web dependency
`@lobehub/icons` version 5.10.0. Source paths are unchanged; SVG circular
arcs are expressed as native circular arcs. The original monochrome variants
are rendered using the package's primary color for Claude Code and Kiro.
Black/white variants adapt to the system appearance for legibility.

Source: https://cdn.jsdelivr.net/npm/@lobehub/icons@5.10.0/es/
(component paths: `<name>/components/Mono.js`; colors: `<name>/style.js`).
The Claude Code component directory is named `ClaudeCode`.

Pi and Hermes reuse the vectors already present in
`web/src/components/icons/PiIcon.tsx` and `HermesIcon.tsx` respectively.
Pi's existing source attribution is https://pi.dev/logo-auto.svg;
Hermes is the repository-authored caduceus, not a third-party brand asset.
Unknown harnesses use a generic system CPU glyph rather than a brand logo.
